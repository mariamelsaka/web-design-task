# 🏠 Simple Website — Home & Contact Us Pages
## 📄 Project Overview
This project contains a basic but elegant website with two main pages:

Home Page: A welcoming landing page showcasing the website’s introduction.

Contact Us Page: A simple form allowing users to send messages or inquiries.

Built with pure HTML, CSS, and Bootstrap, this site emphasizes responsive design and user-friendly navigation.

## ✨ Features
Clean, modern design using Bootstrap 4

Responsive layout for desktop and mobile

Semantic HTML structure for accessibility

Contact form with basic validation (HTML5)

Smooth navigation between pages

## 🛠️ Technologies Used
HTML5

CSS3

Bootstrap 4
